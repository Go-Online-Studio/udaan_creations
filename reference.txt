**System Role & Objective**
Act as an expert UI/UX Designer and Frontend Developer. Your task is to completely redesign a multi-page agency website (Home, About, Contact) from a playful, colorful, "social media/Reels" aesthetic to a highly professional, modern, minimalist, and corporate tech aesthetic. Retain the existing textual content, overall layout grids, and structure, but completely overhaul the styling and design system.

**Design System & Global Styling**

* **Theme:** Strictly Light Theme. Minimalist and clean.
* **Color Palette:** Remove all existing vibrant, multicolored, or "childish" colors (pink, yellow, bright green). Use a sophisticated monochromatic blue palette. Use deep navy for primary text, pure white for backgrounds, off-white/light gray for secondary sections, and professional blue gradients (e.g., `#0052D4` to `#4364F7`) for primary buttons and accents.
* **Typography:** Use a clean, modern sans-serif typeface (like SF Pro, Inter, or Roboto).
* **Shapes & Borders:** Apply "Apple-like" aesthetics. Use smooth, large border-radiuses (`border-radius: 16px` to `24px`) on all cards, buttons, and input fields.
* **UI Effects (Neumorphism & Glassmorphism):**
* Implement subtle, modern neumorphism-like effects. Instead of harsh borders, use soft, diffused drop shadows on cards.
* Use glassmorphism (semi-transparent white backgrounds with `backdrop-filter: blur(12px)`) for sticky headers, overlay cards, or floating elements.


* **Interactions:** Add proper, smooth CSS transitions (`transition: all 0.3s ease-in-out`) to all interactive elements. Buttons and cards should have distinct hover states (slightly lifted with expanded shadows) and active states (pressed in with tighter shadows).

**Assets & Icons (STRICT RULES)**

* **NO EMOJIS:** Absolutely zero emojis are allowed in the text or design.
* **Icons:** Replace all previous emojis and graphic stickers with highly professional, minimalist, inline SVG icons.
* **No External Libraries:** Do not use FontAwesome, Material Icons, or any external CDNs for icons. Write out the pure `<svg>` code directly into the HTML to ensure lightning-fast loading.

**Specific Component Instructions**

1. **Home Page Banner (Mobile Animation):** Retain the structure of the floating mobile phone graphics in the hero section. However, redesign the phones to look like sleek, modern smartphones (glass effect, thin borders) using the blue/monochrome palette. Maintain the floating/bobbing CSS animations.
2. **About Page Banner (Orbit Animation):** Retain the orbital/spinning animation structure in the hero section. Remove the rocket emoji. Replace it with a professional inline SVG icon (like a target, atom, or sleek geometric shape) orbiting a central clean focal point. Update the orbit rings to be subtle, thin gray/blue dashed lines.
3. **Cards (Services/Values):** Remove thick black borders and retro styling. Apply the soft shadow, high-radius Apple aesthetic.
4. **Buttons:** Replace all pill-shaped, brightly colored, hard-shadow buttons with sleek blue gradient buttons featuring soft glowing drop-shadows and subtle hover scaling.
5. **Contact Form:** Redesign the form fields to be clean and minimal. Remove thick borders. Use light gray backgrounds with inset shadows or simple bottom borders that animate to a blue highlight on focus.

**Output Requirements**
Generate the complete production-ready HTML, CSS, and JS (if necessary for the animations/interactions) for this redesign. Ensure the code is semantic, responsive, and adheres strictly to the professional blue/minimalist guidelines provided.
